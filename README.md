# Трихоскоп — веб-приложение

Просмотр изображения с USB-трихоскопа/микроскопа (UVC) в браузере, снимки, скачивание в JPG и PDF.

Работает: iPad с USB-C (Safari), Android с поддержкой внешних USB-камер (Chrome), ПК/Mac.
Не работает через USB на iPhone — iOS не поддерживает внешние USB-камеры.

Снимки хранятся только на устройстве и никуда не отправляются.
